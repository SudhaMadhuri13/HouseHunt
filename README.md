# House Rental Full-Stack Web Application

## 📌 Project Overview
The House Rental Web Application is a full-stack platform that connects property owners and tenants. Property owners can list rental properties, while tenants can browse, search, and submit rental requests. The application is designed with clean, modular architecture to ensure scalability, maintainability, and performance.

---

## ✨ Key Features
- Property listing and management for owners
- Search and filter available rental properties
- Rental request submission and management
- Role-based access control for owners and tenants
- Secure backend APIs
- Clean, reusable, and modular code structure

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

## ⚙️ Application Flow
1. Property owners can add and manage rental property listings  
2. Tenants can search and view available properties  
3. Tenants submit rental requests for selected properties  
4. Role-based access ensures secure and appropriate user actions
